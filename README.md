# TaskPulse ✅

A premium project management task tracker for monitoring developer assignments, Jira tickets, deadlines, and meeting notes.

![Light Theme](https://img.shields.io/badge/Theme-Light-orange) ![Vanilla JS](https://img.shields.io/badge/JS-Vanilla-yellow) ![No Dependencies](https://img.shields.io/badge/Dependencies-None-green)

## Features

- **Task Management** — Add, edit, delete, and track Jira-style tickets (ZST, WP, NET, MOB, CMS + custom types)
- **5-Stage Workflow** — Selected for Development → In Progress → Ready for Testing → Done → Closed
- **Developer Profiles** — Add, edit, and delete team members with task summaries and progress tracking
- **Deadline Countdowns** — Real-time time-remaining indicators with color-coded urgency
- **Meeting Notes** — Attach notes/comments to any task from standups and meetings
- **Search & Filters** — Filter by developer, ticket type, status, or search across all tasks
- **Persistent Storage** — All data saved to `localStorage`
- **Responsive** — Works on desktop, tablet, and mobile

## Tech Stack

- **HTML5** + **CSS3** + **Vanilla JavaScript**
- [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)
- [Lucide Icons](https://lucide.dev/)
- No build step. No framework. Just open `index.html`.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/task-tracker.git

# Open in browser
open task-tracker/index.html
```

Or simply open `index.html` in any modern browser.
